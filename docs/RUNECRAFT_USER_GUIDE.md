# 🔮 Runecraft User Guide
## The Dark Art of Payload Forging

### 📍 **Accessing Runecraft**
1. Navigate to **EXPLOITATION** → **Web & App Exploits**
2. Click the **🔧 Runecraft** tab
3. Enterprise license required for full rune arsenal

---

## 🧙‍♂️ **Interface Overview**

```
[ 🔮 Rune Library ]  →  [ ⚒️ Crafting Grid ]  →  [ 📜 Payload Grimoire ]
```

### **Left Panel: Rune Library**
- Scrollable collection of draggable runes
- Organized by 5 categories with color coding
- Hover for rune descriptions and powers

### **Center Panel: Crafting Grid** 
- 3x3 magical spell grid (9 slots total)
- Drag runes from library into empty slots
- Double-click slots to clear runes

### **Right Panel: Payload Grimoire**
- Real-time output and synergy detection
- Export options: Hex, Python, Binary
- Forged payload preview
