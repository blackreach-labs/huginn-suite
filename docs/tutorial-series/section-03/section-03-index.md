## Section Summary

Section 3 covers passive reconnaissance and intelligence gathering techniques using Huginn's OSINT modules. These 7 videos demonstrate how to collect information about targets without directly interacting with their infrastructure, building on the active enumeration skills from Section 2.

This section uses a **mixed tier model** — five videos cover Free-tier features accessible to all users, while two videos (Breach Intelligence and Threat Intelligence) require the **Enterprise** tier due to their reliance on premium data feeds and custom API integrations (Shodan, VirusTotal, breach databases).

Videos requiring API keys include setup and configuration instructions as part of the demonstration steps.
