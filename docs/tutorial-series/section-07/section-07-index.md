## Section Summary

Section 7 focuses on operational security and stealth capabilities — the Setup (Stealth) phase of the attack chain. These 4 videos demonstrate how to configure Huginn for evasive operations, route traffic through anonymization layers, and deploy cloud-based infrastructure to avoid detection during authorized engagements.

This section is entirely **Professional tier** — all stealth and evasion features require a Professional license or above. No Free-tier features are covered in this section. Viewers must have an active Professional or Enterprise license to use the tools demonstrated here.

All stealth demonstrations in this section use **own cloud infrastructure** and authorized lab environments. The techniques shown are intended for legitimate penetration testing engagements where operational security is a requirement.
