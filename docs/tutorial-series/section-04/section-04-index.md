## Section Summary

Section 4 transitions from passive reconnaissance into active vulnerability scanning — the Scan phase of the attack chain. These 4 videos cover Huginn's built-in scanner from profile selection through results interpretation, culminating in the AI-powered scanning capabilities available at the Enterprise tier.

This section uses a **mixed tier** model: 3 videos cover Free-tier scanning features accessible to all users, while 1 video (AI-Powered Scanning) requires an **Enterprise** license for its neural network analysis and machine learning pattern detection capabilities.

Videos in this section build directly on the reconnaissance data gathered in Sections 2 and 3, showing how enumeration results feed into targeted vulnerability assessment.
